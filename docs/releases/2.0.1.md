## 更新说明

- 修复点击“退出并完成安装”及关闭按钮无响应的问题，确保确认后继续环境安装。
- 修复运行环境安装确认窗口高度不足、退出按钮被遮挡的问题；窗口按内容调整大小，并解除确认阶段的模态锁定，避免多个弹窗叠加时无法操作。
- 修复 H3 视频工作流尺寸识别，按首帧比例和工作流分辨率设置自动计算尺寸，支持手动指定宽高。
- 环境包下载自动检测可用线路，失败时切换线路，支持断点续传与完整性校验。
- 自动下载失败后提供可点击的 123 云盘和百度网盘入口，显示并支持复制提取码，下载后可选择本地环境包安装。

## Release notes

- Fixed unresponsive exit and close actions in the runtime installation confirmation, allowing installation to continue after confirmation.
- Fixed the runtime installation confirmation dialog clipping its exit button. The dialog now sizes to its content and releases the modal grab during confirmation to prevent overlapping dialogs from blocking interaction.
- Fixed dimension detection for H3 video workflows. Output dimensions follow the first-frame aspect ratio and workflow resolution settings, with manual width and height overrides.
- Added automatic runtime download route selection, failover, resumable downloads, and integrity verification.
- Added clickable 123 Cloud Drive and Baidu Netdisk fallback links with visible, copyable extraction codes and local runtime package installation.
