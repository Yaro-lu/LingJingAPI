# 灵境造片厂 2.0.0

**远程调用算力，生成文字、图片和视频。** 在租用的算力服务器上部署服务，自己的电脑和手机通过 URL + API Key 调用。

## 下载

- [服务端程序 · Windows EXE](https://github.com/Yaro-lu/LingJingAPI/releases/download/v2.0.0/LingJingAI-Setup-2.0.0-win-x64.exe)
- [独立运行环境包](https://github.com/Yaro-lu/LingJingAPI/releases/download/v2.0.0/runtime-nvidia-rtx20plus-cu130-v2.0.0.7z)

程序和环境安装在算力端，不包含模型。当前发行包适用于 Windows x64 + NVIDIA 显卡，配套 CUDA 13 环境。

## 三步使用

1. 在算力服务器上安装程序、环境与模型，启动服务。
2. 将公网 URL 和 Key 填入本地客户端页面，或使用手机浏览器连接。
3. 输入提示词或上传参考图，调用远程算力生成作品。
