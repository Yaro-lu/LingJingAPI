# 灵境造片厂 2.0.0

文字、图片、视频生成，ComfyUI 工作流与模型集中管理，支持本机、局域网及公网网页访问和第三方 API 调用。

## 下载

- [Windows 轻量客户端](https://github.com/Yaro-lu/LingJingAPI/releases/download/v2.0.0/LingJingAI-Setup-2.0.0-win-x64.exe)
- [独立 NVIDIA / CUDA 13 运行环境](https://github.com/Yaro-lu/LingJingAPI/releases/download/v2.0.0/runtime-nvidia-rtx20plus-cu130-v2.0.0.7z)

两个包都不包含模型、生成作品、密钥或个人配置。先安装客户端，再通过“模型与环境”下载或导入环境包；模型按工作流单独下载，也可映射已有模型文件。

## 本次更新

- 工作流配置与模型管理合并，列表支持内嵌滚动、右侧操作和缺失模型处理。
- URL 直接打开网页，支持本机、局域网和公网 HTTPS；记住连接，刷新时自动尝试连接。
- 网页项目支持重命名和删除分类，作品按时间分批加载；单用户历史不因更换 URL 或 Key 被清空。
- 图片预览按需加载，点击原图放大；视频使用首帧预览，播放时再加载原文件。
- 图片可加入参考图、复制或删除本地文件；下载名称由提示词生成。
- 每个工作流展示自己的 API 文档；文字工作流区分系统与用户提示词，视频以帧率与时长计算帧数。
- 本地模型映射、相邻目录扫描和可修改目录；ComfyUI 更新增加国内镜像备用渠道。
- Qwen3.5 4B 辅助参数识别增加就绪检查；未部署、服务离线或忙碌时保留规则识别与手动配置。

## 三步体验

1. 安装环境，下载或映射一个可用工作流的模型。
2. 在浏览器打开控制台的 URL，填写 API Key 连接。
3. 选择工作流、输入提示词并生成；点击作品查看原图或播放视频。

[查看截图与完整介绍](https://github.com/Yaro-lu/LingJingAPI#三步演示)

## 兼容性与已知问题

- Windows 10 22H2 / Windows 11 x64，NVIDIA RTX 20 系列及以上；CUDA 13 环境需要 R580 或更高驱动。显存需求以工作流为准。
- 从 1.x 升级时保留配置、模型与输出目录；程序和环境分别更新，使用新版依赖时安装配套 2.0 环境包。
- H3 导入工作流目前使用其内置的 9:16 尺寸，尚未在网页公开比例与参考图尺寸选项；此问题已定位，后续修复。
- 当前按单用户设计，项目记录保存在浏览器，不提供多用户隔离或跨浏览器项目同步。
- 安装包未做代码签名。模型及外部工作流遵守各自的许可证。
