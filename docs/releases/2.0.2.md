## 中文
- 新增“性价比H3”和“高质量H3”，完善模型依赖、视频分类及参数配置。
- 模型下载支持自动测速选源、断线重试、换源续传和完整性校验。
- 支持查找模型来源、选择同名版本、填写地址及复用已确认来源。
- 图生视频默认跟随参考图比例，保留手动尺寸选择。
- 修复网页资源加载，并让首次安装和升级均可选择安装路径。

## English
- Added Cost-effective H3 and High-quality H3 workflows with model dependencies, video classification, and parameter mappings.
- Improved model downloads with source speed checks, retries, resumable failover, and integrity verification.
- Added model source discovery, version selection, manual URLs, and reuse of verified sources.
- Image-to-video now defaults to the reference image aspect ratio while preserving manual sizing.
- Fixed bundled web page loading and enabled installation path selection for both fresh installs and upgrades.
