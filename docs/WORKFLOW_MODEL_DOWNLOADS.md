## 首次安装与一键修复（2026-09-29）

客户端启动时在后台检查运行环境和模型文件大小，不在界面首次绘制时读取大模型哈希或探测下载源。首次安装、环境异常或所选档位缺少模型时显示“环境安装与修复”；可勾选“下次不显示”，也可从“模型与环境”页重新打开。

- 显存 **大于 12 GB**：Qwen3.5、FLUX.2 Klein 4B、性价比H3。
- 显存 **小于等于 12 GB**：Qwen3.5、FLUX.2 Klein 9B、高质量H3。
- 未识别显存时要求手动选择档位。这个档位与模型搭配按当前产品要求保留；实际生成仍取决于显卡和驱动支持。

点击“一键修复”后才逐个校验已有模型的 SHA256，保留并隔离不匹配的本地文件，沿用现有测速选源、重试、断点续传与大小/SHA256 校验下载缺失项。运行环境需替换时使用独立更新助手安全退出并自动重启客户端，重启后继续所选档位。模型齐全后重启后台，以服务端健康信息确认文字、图片和视频三个工作流可用；确认失败会保留已完成文件并显示原因。显卡或 NVIDIA 驱动检查失败时直接提示，避免反复下载无法修复硬件问题的环境包。此可用性检查不代替实际 GPU 生成验收。

专项测试覆盖 12 GB 边界、真实模型清单、轻量启动判断、跨重启状态、异常文件保留、运行环境自动重启交接、驱动失败和后台验证等待。2.0.3 程序安装包已构建，580 项 Python 回归及页面脚本测试通过（另有 1 项条件跳过）；未在本机下载完整模型或进行 GPU 生成。

## 下载方式

模型下载同时读取镜像和官方源的小块数据，校验响应大小后按吞吐速度选源。临时断线自动重试，持续失败换源；以已记录的大小与 SHA256 确认断点属于同一文件，跨源不复用原服务器 ETag。不支持续传时从头安全下载。只有大小与 SHA256 均通过后才成为正式模型文件。

模型来源优先使用工作流声明、内置清单和此前核验的记录。其他来源从模型索引按准确文件名查找，通过 Hugging Face 文件元数据固定提交版本、核验大小和 LFS SHA256。同名不同内容必须由用户选择；未知、私有或未收录模型可填写地址或选择本地文件，不使用文字模型猜链接。

“填写地址”可直接打开，无需等待索引查找；在线核验支持 Hugging Face 文件页或直链，其他来源可先下载后选择本地模型。部分同名候选核验失败时，不把剩余的一个候选误判为唯一版本。确认过的来源写入 `runtime/model_sources.json`，并发保存采用锁和原子替换。
